# My Site — Портфолио @onozis

Личный сайт-портфолио, написанный с нуля на чистом HTML, CSS и JavaScript. Без фреймворков и библиотек (кроме шрифтов Google).

## 🚀 Что внутри

- **Анимированный зимний фон** — падающий снег на Canvas.
- **Музыкальный плеер** — фоновое воспроизведение с кастомным эквалайзером (3 палочки), который плавно реагирует на включение и выключение.
- **Переключатель тем** — тёмная и светлая тема (луна/солнце в меню).
- **Плавная загрузка** — экран загрузки ресурсов от 1% до 100%, после чего нужно кликнуть в любом месте, чтобы попасть на сайт.
- **Игра Neon Snake** — встроенная мини-игра (змейка) на Canvas с неоновой графикой, управлением на WASD и свайпами для телефона. Находится в папке `/snake`.
- **Адаптивность** — сайт корректно отображается на телефонах и планшетах.

## 🛠️ Стек

- HTML5 (Canvas, Audio, Semantic tags)
- CSS3 (Variables, Flexbox, Grid, Animations, Media queries)
- JavaScript (Vanilla, без библиотек)
- Google Fonts (Inter)
